# Prompts.md — CoverCraft AI

## 1. Project Planning
Used AI to understand the requirements and plan the AI Cover Letter Generator with demo mode, Gemini API integration, and resume PDF upload.

## 2. UI/UX Design
Used AI to learn how to create a clean, modern, responsive SaaS interface with reusable components and accessible forms.

## 3. React State Management
Used AI to understand React hooks, form handling, validation, loading states, and updating the generated cover letter.

## 4. Template Generation
Used AI to learn JavaScript template strings and generate personalized cover letters using user input without an API key.

## 5. Gemini API Integration
Used AI to understand API requests, server-side Gemini integration, asynchronous functions, and error handling.

## 6. API Key Security
Learned how to use environment variables, `.env`, `.gitignore`, and backend routes to protect the Gemini API key.

## 7. Resume PDF Parsing
Used AI to understand PDF.js, text extraction, file validation, and handling unsupported or scanned PDFs.

## 8. Testing and Debugging
Used AI to understand build errors, validate form behavior, test demo mode, and troubleshoot API failures.

## 9. Improvements
Used AI assistance to improve code structure, responsive design, accessibility, documentation, and overall application reliability.

**Note:** AI was used as a learning and development assistant to understand concepts, solve problems, and improve the implementation.
